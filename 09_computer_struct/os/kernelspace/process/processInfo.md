# 进程及其组成

## 一、进程的概念

### 1.1 定义

**进程（Process）** 是程序在一个数据集合上的一次运行过程，是操作系统进行**资源分配**和**调度**的基本单位。

### 1.2 进程与程序的区别

| 比较项 | 程序 | 进程 |
|--------|------|------|
| 本质 | 静态的指令集合 | 动态的执行过程 |
| 存在形式 | 存储在磁盘上的文件 | 存在于内存中的运行实体 |
| 生命周期 | 永久保存 | 有创建、运行、消亡的过程 |
| 并发性 | 无 | 有，多个进程可并发执行 |
| 对应关系 | 一个程序可对应多个进程 | 一个进程对应一个程序 |
| 类比 | 菜谱 | 正在做菜的过程 |

### 1.3 进程的特征

- **动态性**：进程有产生、发展和消亡的过程
- **并发性**：多个进程可以同时存在于内存中并发运行
- **独立性**：进程是独立运行和获得资源的基本单位
- **异步性**：各进程按各自独立的、不可预知的速度向前推进
- **结构性**：每个进程都有特定的结构组成

## 二、进程的组成

一个完整的进程由以下三部分组成：

```text
进程
├── 程序段（代码段）
├── 数据段
└── 进程控制块（PCB）
```

### 2.1 程序段（代码段 / Text Segment）

- **内容**：进程要执行的程序指令
- **特点**：
  - 通常是只读的，防止被意外修改
  - 多个进程执行同一程序时，可共享同一份代码段
  - 由操作系统的加载器从磁盘加载到内存

### 2.2 数据段（Data Segment）

数据段又细分为多个区域：

| 区域 | 内容 | 说明 |
|------|------|------|
| 全局数据区 | 全局变量、静态变量 | 程序启动时分配，程序结束时释放 |
| 堆区（Heap） | 动态分配的内存（如malloc/new） | 由程序员手动管理，向高地址增长 |
| 栈区（Stack） | 局部变量、函数参数、返回地址 | 由系统自动管理，向低地址增长 |
| 常量区 | 字符串常量等 | 通常只读 |

**内存布局示意：**

```text
高地址
┌──────────────────┐
│       栈区        │  ← 向下增长（局部变量、函数调用）
│       Stack       │
├──────────────────┤
│        ↓         │
│                  │
│        ↑         │
├──────────────────┤
│       堆区        │  ← 向上增长（动态分配）
│       Heap       │
├──────────────────┤
│   全局/静态数据区  │  ← 全局变量、静态变量
├──────────────────┤
│     代码段        │  ← 程序指令（只读）
└──────────────────┘
低地址
```

### 2.3 进程控制块（PCB, Process Control Block）

**PCB 是进程存在的唯一标志**，操作系统通过 PCB 来感知和管理进程。每个进程有且仅有一个 PCB。

#### PCB 的内容：

| 类别 | 具体内容 | 说明 |
|------|----------|------|
| 进程标识信息 | PID（进程标识符） | 唯一标识一个进程 |
| | PPID（父进程标识符） | 标识创建该进程的进程 |
| | UID（用户标识符） | 标识进程的所有者 |
| 处理机状态信息 | 程序计数器（PC） | 指向下一条要执行的指令地址 |
| | 通用寄存器内容 | 进程被切换时保存的寄存器值 |
| | 栈指针（SP） | 指向进程栈顶 |
| | 程序状态字（PSW） | 包含条件码、中断标志等 |
| 进程调度信息 | 进程状态 | 就绪、运行、阻塞等 |
| | 优先级 | 调度时参考 |
| | 已等待时间 | 用于老化机制 |
| | 已执行时间 | 统计用 |
| 进程控制信息 | 程序和数据地址 | 指向代码段和数据段 |
| | 进程同步和通信机制 | 信号量、消息队列等 |
| | 资源清单 | 进程已获得的资源列表 |
| | 链接指针 | 指向就绪队列、阻塞队列等 |
| | 打开文件列表 | 进程打开的文件描述符 |

#### PCB 的组织方式：

```text
方式一：链接方式
┌──────┐    ┌──────┐    ┌──────┐    ┌──────┐
│ PCB1 │───→│ PCB2 │───→│ PCB3 │───→│ PCB4 │───→ NULL
└──────┘    └──────┘    └──────┘    └──────┘
（同一状态的PCB链接在同一队列中）

方式二：索引方式
┌──────────────┐
│  就绪表索引    │──→ [PCB1, PCB3, PCB5]
├──────────────┤
│  阻塞表索引    │──→ [PCB2, PCB4]
├──────────────┤
│  运行表索引    │──→ [PCB6]
└──────────────┘
```

## 三、进程的状态与转换

### 3.1 三态模型

```text
                    时间片用完 / 被高优先级抢占
              ┌─────────────────────────────────┐
              ↓                                 │
        ┌──────────┐                    ┌──────────┐
        │   就绪态  │ ─────────────────→ │   运行态  │
        │  Ready    │   被调度（获得CPU） │  Running  │
        └──────────┘                    └──────────┘
              ↑                                 │
              │                                 │
              │  I/O完成 / 等待事件发生           │  等待事件（如I/O请求）
              │                                 ↓
        ┌──────────┐                    ┌──────────┐
        │   阻塞态  │                    │   阻塞态  │
        │ Blocked   │                    │ Blocked   │
        └──────────┘                    └──────────┘
```

### 3.2 五态模型（加入创建态和终止态）

```text
创建态 → 就绪态 ⇄ 运行态 → 终止态
                  ↕
                阻塞态
```

### 3.3 状态转换说明

| 转换 | 触发条件 |
|------|----------|
| 创建 → 就绪 | 进程被创建，资源分配完毕 |
| 就绪 → 运行 | 被调度程序选中，获得CPU |
| 运行 → 就绪 | 时间片用完或被更高优先级进程抢占 |
| 运行 → 阻塞 | 等待某事件（如I/O请求、等待信号） |
| 阻塞 → 就绪 | 等待的事件完成（如I/O完成） |
| 运行 → 终止 | 进程执行完毕或被强制终止 |

## 四、进程的创建与终止

### 4.1 进程创建

引起进程创建的事件：

1. 用户登录
2. 作业调度
3. 提供服务（如打印请求）
4. 应用请求（如进程调用fork()创建子进程）

**创建过程：**

```text
1. 申请空白PCB
2. 为新进程分配资源（内存、I/O设备等）
3. 初始化PCB（设置PID、优先级、寄存器初值等）
4. 将新进程插入就绪队列
```

### 4.2 进程终止

引起进程终止的事件：

- 正常结束（执行完毕）
- 出错终止（如除零错误、非法指令）
- 外界干预（如用户强制终止、操作系统因死锁终止）

**终止过程：**

```text
1. 根据PID查找PCB
2. 若进程正在运行，立即停止，释放CPU
3. 释放进程占用的所有资源（内存、文件、设备等）
4. 从所在队列中移除PCB
5. 回收PCB
```

## 五、进程的挂起与激活

### 5.1 挂起的原因

- 内存空间紧张，需将部分进程换出到磁盘
- 父进程需要考察或修改子进程
- 操作系统需要检查资源使用情况
- 用户请求（如调试程序）

### 5.2 引入挂起后的状态模型（七态模型）

```text
        创建态
          ↓
      就绪态 ←──────→ 就绪挂起态
        ↓    激活         ↑
      运行态              │ 换出
        ↓                 │
      阻塞态 ←──────→ 阻塞挂起态
        ↓
      终止态
```

## 六、总结

```text
进程
├── 概念：程序的一次动态执行过程
├── 组成
│   ├── 程序段（代码）
│   ├── 数据段（全局变量、堆、栈）
│   └── PCB（进程控制块）——进程存在的唯一标志
├── 状态
│   ├── 三态：就绪、运行、阻塞
│   └── 五态/七态：加入创建、终止、挂起
├── 操作
│   ├── 创建
│   ├── 调度
│   ├── 阻塞/唤醒
│   ├── 挂起/激活
│   └── 终止
└── 意义：操作系统资源分配和CPU调度的基本单位
```

> **一句话总结**：进程 = 程序段 + 数据段 + PCB。其中 PCB 是操作系统管理进程的"身份证"，是进程存在的唯一标志。
