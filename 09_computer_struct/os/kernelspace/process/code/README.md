# 处理器管理（进程调度）模拟器

## 项目结构
process_manager/ ├── Makefile # 构建脚本 ├── README.md # 本文件 ├── include/ # 头文件 │ ├── pcb.h # 进程控制块定义 │ ├── queue.h # 就绪队列定义 │ ├── scheduler.h # 调度器接口 │ ├── cpu.h # CPU模拟定义 │ └── stats.h # 统计输出接口 ├── src/ # 源文件 │ ├── pcb.c # 进程创建与销毁 │ ├── queue.c # 队列操作实现 │ ├── scheduler.c # 调度算法实现 │ ├── cpu.c # CPU模拟执行 │ ├── stats.c # 统计与甘特图 │ └── main.c # 主函数与测试用例 └── obj/ # 编译中间文件（自动生成） └── bin/ # 可执行文件（自动生成）


## 编译与运行

```bash
make        # 编译
make run    # 编译并运行
make clean  # 清理
支持的调度算法
算法	说明
FCFS	先来先服务
SJF	短作业优先（非抢占）
RR	时间片轮转（时间片=3）
Priority	优先级调度（非抢占）
输出内容
逐时间片执行日志
就绪队列状态
统计报告（周转时间、等待时间、响应时间）
甘特图
