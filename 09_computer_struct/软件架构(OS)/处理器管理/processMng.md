# 操作系统的处理器管理

## 一、概述

处理器（CPU）是计算机中最核心的资源之一。操作系统通过**进程管理**和**调度机制**来合理分配和高效利用处理器资源，使多个程序能够并发执行，提高系统吞吐量和资源利用率。

---

## 二、进程与线程

### 2.1 进程（Process）

- **定义**：进程是程序的一次执行过程，是系统进行资源分配和调度的基本单位。
- **组成**：
  - 程序代码（Text）
  - 数据段（Data）
  - 进程控制块（PCB）
- **状态转换**：

```text
        创建
         ↓
      ┌──────┐    时间片用完    ┌──────┐
      │ 就绪 │ ──────────────→ │ 运行 │
      │ Ready │ ←────────────── │ Run  │
      └──────┘    获得CPU      └──────┘
         ↑                        │
         │  I/O完成               │ 等待I/O
         │                        ↓
      ┌──────┐                ┌──────┐
      │ 阻塞 │ ←───────────── │ 阻塞 │
      │Blocked│               │Blocked│
      └──────┘                └──────┘
```

### 2.2 线程（Thread）

- **定义**：线程是进程内的一个执行单元，是CPU调度的基本单位。
- **与进程的区别**：

| 比较项 | 进程 | 线程 |
|--------|------|------|
| 资源分配 | 独立地址空间 | 共享所属进程的资源 |
| 切换开销 | 较大 | 较小 |
| 通信方式 | 需要IPC机制 | 可直接访问共享内存 |
| 独立性 | 强 | 弱 |

## 三、进程调度

### 3.1 调度层次

| 层次 | 名称 | 功能 | 频率 |
|------|------|------|------|
| 高级调度 | 作业调度 | 决定哪个作业进入内存 | 低 |
| 中级调度 | 内存调度 | 决定挂起/换入进程 | 中 |
| 低级调度 | 进程调度 | 决定哪个就绪进程获得CPU | 高 |

### 3.2 调度算法

#### （1）先来先服务（FCFS）

- 按到达顺序依次执行
- **优点**：实现简单，公平
- **缺点**：平均等待时间较长，存在"护航效应"

#### （2）短作业优先（SJF）

- 优先执行预计运行时间最短的作业
- **优点**：平均等待时间最短
- **缺点**：可能导致长作业饥饿

#### （3）优先级调度

- 每个进程赋予优先级，高优先级优先执行
- 分为**抢占式**和**非抢占式**
- 需配合**老化机制**防止低优先级饥饿

#### （4）时间片轮转（RR）

- 每个进程分配一个时间片，轮流执行
- 时间片用完则切换到下一个进程
- **优点**：响应时间好，适合交互式系统
- **关键**：时间片大小需合理（通常10~100ms）

#### （5）多级反馈队列

- 设置多个优先级队列，时间片逐级增大
- 新进程进入最高优先级队列
- 用完时间片未完成的降级到下一级队列
- **综合优点**：兼顾响应时间和吞吐量

## 四、进程同步与互斥

### 4.1 基本概念

- **互斥**：多个进程不能同时访问临界资源
- **同步**：进程之间按一定顺序协调执行

### 4.2 实现机制

| 机制 | 说明 |
|------|------|
| 信号量（Semaphore） | P/V操作实现互斥与同步 |
| 管程（Monitor） | 封装共享资源，提供条件变量 |
| 互斥锁（Mutex） | 锁定/解锁机制 |
| 自旋锁（Spinlock） | 忙等待方式获取锁 |

### 4.3 经典同步问题

- **生产者-消费者问题**：缓冲区有限，需同步生产和消费
- **读者-写者问题**：多读单写，需协调并发访问
- **哲学家进餐问题**：资源竞争与死锁预防

---

## 五、进程通信（IPC）

| 方式 | 特点 |
|------|------|
| 共享内存 | 速度最快，需配合同步机制 |
| 消息传递 | 通过send/receive原语通信 |
| 管道（Pipe） | 半双工，适合父子进程 |
| 套接字（Socket） | 支持网络通信 |
| 信号（Signal） | 异步通知机制 |

---

## 六、死锁

### 6.1 死锁产生的四个必要条件

1. **互斥条件**：资源一次只能被一个进程使用
2. **请求与保持**：持有资源的同时请求新资源
3. **不可剥夺**：已分配的资源不能被强行回收
4. **循环等待**：存在进程间的环形等待链

### 6.2 死锁处理策略

| 策略 | 方法 |
|------|------|
| 预防 | 破坏四个必要条件之一 |
| 避免 | 银行家算法，动态判断安全状态 |
| 检测与恢复 | 资源分配图检测，撤销/剥夺恢复 |
| 忽略 | 鸵鸟策略（多数现代OS采用） |

## 七、总结

```text
操作系统处理器管理
├── 进程管理
│   ├── 进程创建与撤销
│   ├── 进程状态转换
│   └── 进程控制块（PCB）
├── 线程管理
│   ├── 用户级线程
│   └── 内核级线程
├── 处理器调度
│   ├── 调度算法
│   └── 调度时机
├── 同步与互斥
│   ├── 信号量
│   └── 管程
├── 进程通信
└── 死锁处理
```

操作系统通过以上机制，实现了对处理器资源的**高效分配**、**公平共享**和**安全使用**，是现代多任务系统的基石。
