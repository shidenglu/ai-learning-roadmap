# 程序内存布局：各段存放内容详解

## 一、整体内存布局

```text
高地址
┌──────────────────────────────────┐
│            栈区（Stack）           │  ← 向下增长
├──────────────────────────────────┤
│              ↓                    │
│                                  │
│              ↑                    │
├──────────────────────────────────┤
│            堆区（Heap）            │  ← 向上增长
├──────────────────────────────────┤
│         .bss 段                  │
├──────────────────────────────────┤
│         .data 段                 │
├──────────────────────────────────┤
│         .rodata 段               │
├──────────────────────────────────┤
│         .text 段（代码段）         │
├──────────────────────────────────┤
│         ELF Header               │
└──────────────────────────────────┘
低地址
```

---

## 二、各段详细介绍

### 2.1 代码段（.text）

| 项目 | 说明 |
|------|------|
| 存放内容 | 程序的**机器指令**（编译后的二进制代码） |
| 权限 | 只读 + 可执行（r-x） |
| 大小确定时机 | 编译链接时确定，运行时不变 |
| 是否共享 | 多进程运行同一程序时可共享同一份代码段 |

**具体包含：**

```text
.text 段
├── main() 的机器码
├── 自定义函数的机器码（如 add()、func()）
├── 调用的库函数的机器码（静态链接时）
├── 跳转指令、分支指令
└── 系统调用的入口代码
```

**示例：**

```c
int add(int a, int b) {
    return a + b;    // ← 这些指令编译后存在 .text 段
}

int main() {
    int c = add(1, 2);  // ← main 的指令也在 .text 段
    return 0;
}
```

---

### 2.2 只读数据段（.rodata）

| 项目 | 说明 |
|------|------|
| 存放内容 | **只读**的常量数据 |
| 权限 | 只读（r--） |
| 大小确定时机 | 编译时确定 |

**具体包含：**

```text
.rodata 段
├── 字符串常量（如 "hello world"）
├── printf 的格式串（如 "%d\n"）
├── const 修饰的全局变量
├── switch 语句的跳转表
└── 浮点常量
```

**示例：**

```c
const int MAX = 100;              // ← .rodata
const char *msg = "hello";       // "hello" 字符串 → .rodata

void func() {
    printf("result = %d\n", 42); // "result = %d\n" → .rodata
}
```

---

### 2.3 已初始化数据段（.data）

| 项目 | 说明 |
|------|------|
| 存放内容 | **已赋初值**的全局变量和静态变量 |
| 权限 | 可读 + 可写（rw-） |
| 大小确定时机 | 编译时确定 |
| 初始值来源 | 存储在可执行文件中，程序加载时复制到内存 |

**具体包含：**

```text
.data 段
├── 已初始化的全局变量
├── 已初始化的静态变量（static）
├── 已初始化的全局指针
└── 已初始化的全局结构体/数组
```

**示例：**

```c
int g_var = 100;                  // ← .data（全局，有初值）
static int s_var = 200;          // ← .data（静态，有初值）
char *p = "hello";               // ← .data（指针本身，值为"hello"的地址）
int arr[3] = {1, 2, 3};         // ← .data（已初始化的全局数组）
struct Point pt = {1, 2};       // ← .data（已初始化的全局结构体）
```

---

### 2.4 未初始化数据段（.bss）

| 项目 | 说明 |
|------|------|
| 存放内容 | **未赋初值**（或初值为0）的全局变量和静态变量 |
| 权限 | 可读 + 可写（rw-） |
| 特点 | 不占可执行文件空间（只记录大小，加载时自动清零） |
| 名字由来 | Block Started by Symbol |

**具体包含：**

```text
.bss 段
├── 未初始化的全局变量
├── 初始化为0的全局变量
├── 未初始化的静态变量
└── 未初始化的全局数组/结构体
```

**示例：**

```c
int g_var;                       // ← .bss（未初始化，默认为0）
static int s_var;                // ← .bss
int g_zero = 0;                  // ← .bss（显式初始化为0，编译器优化放入bss）
char buf[1024];                  // ← .bss（未初始化的全局数组）
int arr[5];                      // ← .bss
```

> ⚠️ **注意**：`.bss` 段在可执行文件中**不占实际空间**，只记录需要多少字节。程序加载时由操作系统分配并清零。

---

### 2.5 堆区（Heap）

| 项目 | 说明 |
|------|------|
| 存放内容 | 程序员**动态分配**的内存 |
| 管理方式 | malloc/calloc/realloc 分配，free 释放 |
| 增长方向 | 向高地址增长 |
| 大小 | 运行时动态变化，受系统可用内存限制 |
| 生命周期 | 由程序员决定，不自动释放 |

**具体包含：**

```text
堆区
├── malloc() 分配的内存
├── calloc() 分配的内存
├── realloc() 重新分配的内存
├── new 操作符分配的对象（C++）
└── 动态数组、动态结构体等
```

**示例：**

```c
void func() {
    int *p = (int *)malloc(10 * sizeof(int));   // ← 堆上 40 字节
    char *s = (char *)calloc(100, 1);           // ← 堆上 100 字节（清零）
    struct Node *n = (struct Node *)malloc(sizeof(struct Node)); // ← 堆上

    // 使用完毕后必须手动释放
    free(p);
    free(s);
    free(n);
}
```

---

### 2.6 栈区（Stack）

| 项目 | 说明 |
|------|------|
| 存放内容 | 函数的**局部变量**、参数、返回地址等 |
| 管理方式 | 系统自动分配和释放 |
| 增长方向 | 向低地址增长 |
| 大小 | 通常有限（Linux 默认 8MB） |
| 生命周期 | 函数调用期间存在，函数返回后自动释放 |

**具体包含：**

```text
栈区
├── 局部变量（int a; char buf[64];）
├── 函数参数
├── 返回地址（调用者下一条指令的地址）
├── 保存的寄存器值（栈帧）
├── 局部数组
├── 局部结构体
└── 局部指针变量（指针本身，不是指向的内容）
```

**示例：**

```c
int add(int a, int b) {     // a, b 参数 → 栈
    int sum = a + b;        // sum → 栈
    return sum;
}

void func() {
    int x = 10;             // x → 栈
    char buf[64];           // buf → 栈（64字节）
    int *p = &x;           // p → 栈（指针本身），指向的 x 也在栈
    struct Point pt = {1,2}; // pt → 栈
    add(x, 20);            // 函数调用时压栈
}
```

**栈帧结构：**

```text
高地址
┌─────────────────────────────┐
│  调用者栈帧                   │
├─────────────────────────────┤
│  参数 b                      │
│  参数 a                      │
├─────────────────────────────┤
│  返回地址（调用add的下一条指令）│
├─────────────────────────────┤
│  保存的 ebp/rbp              │
├─────────────────────────────┤
│  局部变量 sum                │  ← 当前函数的栈帧
├─────────────────────────────┤
│  ...                        │
└─────────────────────────────┘
低地址
```

---

### 2.7 内核空间

| 项目 | 说明 |
|------|------|
| 位置 | 虚拟地址空间最高处（通常高1GB或2GB） |
| 权限 | 用户态不可直接访问 |
| 内容 | 操作系统内核代码、内核数据结构、页表等 |

```text
┌─────────────────────────────┐ 0xFFFFFFFF
│       内核空间               │  ← 用户程序不可访问
├─────────────────────────────┤ 0xC0000000（32位）
│       用户空间               │  ← 用户程序的活动区域
│  （栈、堆、bss、data、text）  │
└─────────────────────────────┘ 0x00000000
```

## 三、对比总结

| 段 | 存放内容 | 分配时机 | 释放时机 | 权限 | 大小变化 |
|----|---------|---------|---------|------|---------|
| .text | 机器指令 | 程序加载时 | 程序退出时 | r-x | 固定 |
| .rodata | 字符串常量、const变量 | 程序加载时 | 程序退出时 | r-- | 固定 |
| .data | 已初始化的全局/静态变量 | 程序加载时 | 程序退出时 | rw- | 固定 |
| .bss | 未初始化的全局/静态变量 | 程序加载时 | 程序退出时 | rw- | 固定 |
| 堆（Heap） | 动态分配的内存 | malloc/new 时 | free/delete 时 | rw- | 动态变化 |
| 栈（Stack） | 局部变量、参数、返回地址 | 函数调用时 | 函数返回时 | rw- | 动态变化 |
| 内核空间 | OS内核代码和数据 | 系统启动时 | 关机 | 用户不可访问 | — |

## 四、完整示例

```c
#include <stdio.h>
#include <stdlib.h>

int g_init = 100;              // → .data
int g_uninit;                  // → .bss
const char *msg = "hello";    // 指针msg → .data，"hello" → .rodata
const int LIMIT = 999;        // → .rodata

int add(int a, int b) {       // 函数代码 → .text
    int sum = a + b;          // sum → 栈
    return sum;
}

int main() {
    int local = 10;                       // → 栈
    static int s_local = 20;              // → .data（静态已初始化）
    static int s_uninit;                  // → .bss（静态未初始化）
    char buf[32];                         // → 栈
    int *heap_ptr = (int *)malloc(4);    // heap_ptr → 栈，指向的4字节 → 堆
    *heap_ptr = 42;

    printf("%d\n", add(g_init, local));  // "%d\n" → .rodata

    free(heap_ptr);                      // 释放堆内存
    return 0;
}
```

**各变量归属：**

```text
┌─────────────────────────────────────────────────┐
│ .text     │ add()机器码、main()机器码            │
├─────────────────────────────────────────────────┤
│ .rodata   │ "hello"、"%d\n"、LIMIT=999          │
├─────────────────────────────────────────────────┤
│ .data     │ g_init=100、msg指针、s_local=20      │
├─────────────────────────────────────────────────┤
│ .bss      │ g_uninit、s_uninit                   │
├─────────────────────────────────────────────────┤
│ 堆 Heap   │ *heap_ptr = 42（malloc的4字节）      │
├─────────────────────────────────────────────────┤
│ 栈 Stack  │ local、buf[32]、heap_ptr指针、       │
│           │ add()的参数a、b和局部变量sum          │
└─────────────────────────────────────────────────┘
```

## 五、常见误区

| 误区 | 正确理解 |
|------|---------|
| "局部变量都在栈上" | ✅ 正确（除非是 static 局部变量） |
| "指针在堆上" | ❌ 指针本身在栈/数据段，指向的内容可能在堆上 |
| "malloc 的变量在栈上" | ❌ malloc 的内容在堆上 |
| "const 变量都在 .rodata" | ⚠️ 局部 const 可能仍在栈上（取决于编译器优化） |
| "字符串都在 .rodata" | ⚠️ 字符串字面量在 .rodata，但 char s[]="hi" 会复制到栈 |
| "全局变量都在 .data" | ❌ 未初始化的在 .bss |

```bash
# 详细查看

# 查看符号归属

```

## 七、总结图

```text
程序内存布局（从高到低）
┌──────────────────────────────────────────────┐
│  内核空间（用户不可访问）                       │
├──────────────────────────────────────────────┤
│  栈区 Stack                                   │
│  → 局部变量、函数参数、返回地址、栈帧           │
│  → 自动分配释放，向下增长                      │
├──────────────────────────────────────────────┤
│                  ↕ 空闲空间                    │
├──────────────────────────────────────────────┤
│  堆区 Heap                                    │
│  → malloc/new 动态分配的内存                   │
│  → 手动管理，向上增长                          │
├──────────────────────────────────────────────┤
│  .bss 段                                     │
│  → 未初始化全局/静态变量（自动清零）            │
├──────────────────────────────────────────────┤
│  .data 段                                    │
│  → 已初始化全局/静态变量                       │
├──────────────────────────────────────────────┤
│  .rodata 段                                  │
│  → 字符串常量、const 全局变量                  │
├──────────────────────────────────────────────┤
│  .text 段                                    │
│  → 机器指令（函数代码）                        │
├──────────────────────────────────────────────┤
│  ELF Header / Program Header                 │
└──────────────────────────────────────────────┘
```

> **一句话总结**：代码段放指令，只读段放常量，data 段放有初值的全局变量，bss 段放无初值的全局变量，堆放动态分配的内存，栈放局部变量和函数调用信息。
