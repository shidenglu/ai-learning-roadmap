# HDD（Hard Disk Drive）机械硬盘

## 1. 概述

HDD（Hard Disk Drive）即机械硬盘，是一种利用磁性介质存储数据的非易失性存储设备。数据保存在高速旋转的磁盘表面，通过磁头完成数据的读写操作。

特点：

- 断电后数据不会丢失
- 容量大
- 单位容量成本低
- 存在机械运动部件
- 随机访问速度较慢

---

## 2. 硬件结构

```text
+------------------------------------------------+
|                    HDD                         |
|                                                |
|   +--------------------------+                 |
|   |        Platter           |                 |
|   |        (盘片)             |                 |
|   +--------------------------+                 |
|                ↑                               |
|                │                               |
|         +-------------+                        |
|         |    Head     |                        |
|         |   (磁头)     |                        |
|         +-------------+                        |
|                ↑                               |
|                │                               |
|         +-------------+                        |
|         | Actuator    |                        |
|         |  (摆臂)      |                        |
|         +-------------+                        |
|                                                |
|         Spindle Motor                          |
|          (主轴电机)                             |
+------------------------------------------------+
```

主要组成：

- 盘片（Platter）
- 磁头（Head）
- 摆臂（Actuator Arm）
- 主轴电机（Spindle Motor）
- 控制器（Controller）
- 缓存（Cache）

---

## 3. 数据组织方式

### 磁道（Track）

盘片表面被划分为多个同心圆。

```text
+------------------+
|    Track 0       |
|   Track 1        |
|  Track 2         |
| Track 3          |
+------------------+
```

---

### 扇区（Sector）

每个磁道被划分成多个扇区。

```text
Track
 ├── Sector 0
 ├── Sector 1
 ├── Sector 2
 └── ...
```

常见大小：

- 512 Bytes
- 4 KB（Advanced Format）

---

### 柱面（Cylinder）

多个盘面上相同半径的磁道组成一个柱面。

```text
Head0 Track10
Head1 Track10
Head2 Track10
Head3 Track10
      ↓
   Cylinder10
```

---

## 4. 工作原理

### 写数据

```text
CPU
 ↓
文件系统
 ↓
磁盘驱动
 ↓
HDD控制器
 ↓
磁头
 ↓
盘片磁化
```

通过改变磁介质磁场方向表示：

```text
0
1
```

---

### 读数据

```text
盘片磁场
 ↓
磁头感应
 ↓
控制器解码
 ↓
CPU
```

磁头检测磁场变化并恢复原始数据。

---

## 5. 地址访问方式

### CHS（早期）

```text
Cylinder
Head
Sector
```

通过：

- 柱面号
- 磁头号
- 扇区号

定位数据。

---

### LBA（现代）

```text
LBA0
LBA1
LBA2
LBA3
...
```

操作系统只看到连续编号的逻辑块地址。

现代硬盘全部采用LBA寻址。

## 7. HDD性能指标

### 转速（RPM）

表示盘片每分钟旋转次数。

常见：

- 5400 RPM
- 7200 RPM
- 10000 RPM
- 15000 RPM（企业级）

---

### 寻道时间（Seek Time）

磁头移动到目标磁道所需时间。

典型：

```text
5~10 ms
```

---

### 旋转延迟（Rotational Latency）

等待目标扇区转到磁头下方。

7200 RPM：

```text
≈ 4.17 ms
```

---

### 顺序读写速度

消费级机械硬盘：

```text
100 ~ 250 MB/s
```

企业级机械硬盘：

```text
200 ~ 300 MB/s
```

---

### 缓存（Cache）

用于缓存热点数据。

常见：

```text
64MB
128MB
256MB
512MB
```

---

## 8. HDD接口

### SATA HDD

最常见的消费级接口。

```text
HDD
 ↓
SATA
 ↓
主板
```

速度：

```text
6 Gbps
≈ 600 MB/s
```

---

### SAS HDD

服务器常用接口。

```text
HDD
 ↓
SAS
 ↓
RAID/HBA
 ↓
服务器
```

特点：

- 支持双端口
- 更高可靠性
- 更高并发能力

---

## 9. HDD与SSD对比

| 项目 | HDD | SSD |
|--------|--------|--------|
| 存储介质 | 磁盘 | Flash |
| 是否机械结构 | 是 | 否 |
| 容量成本 | 低 | 高 |
| 顺序读写 | 100~250MB/s | 500~14000MB/s |
| 随机访问 | 慢 | 快 |
| 功耗 | 较高 | 较低 |
| 噪音 | 有 | 无 |
| 抗震能力 | 较差 | 较强 |

## 11. 典型应用场景

适合：

- NAS存储
- 数据备份
- 视频监控
- 文件服务器
- 冷数据归档

不适合：

- AI训练
- 数据库高并发访问
- 高频随机IO场景
- 操作系统高性能启动盘

---

## 12. 总结

HDD是一种利用磁盘旋转和磁头读写实现数据存储的机械式存储设备。

核心特点：

- 大容量
- 低成本
- 非易失存储
- 存在机械运动结构
- 随机访问速度较慢

数据路径：

CPU → 文件系统 → 块设备驱动 → SATA/SAS控制器 → HDD控制器 → 磁头 → 盘片

在现代计算机中，HDD主要承担海量数据存储和长期归档任务，而SSD则负责高性能数据访问。
