# Pandas 库介绍

| 函数                 | 主要功能            | 深度学习中的用途       |
| ------------------ | --------------- | -------------- |
| `pd.read_csv()`    | 读取 CSV 文件       | 读取训练数据         |
| `df.head()`        | 查看前几行           | 快速检查数据         |
| `df.info()`        | 查看数据结构和类型       | 检查数据类型、缺失值     |
| `df.describe()`    | 查看数值统计信息        | 分析数据分布         |
| `df.isnull()`      | 检查缺失值           | 找出异常数据         |
| `df.fillna()`      | 填充缺失值           | 数据清洗           |
| `df.drop()`        | 删除行或列           | 删除无用特征         |
| `df.groupby()`     | 分组统计            | 对数据进行分类统计      |
| `pd.get_dummies()` | 类别变量 One-Hot 编码 | 把字符串类别转换成数字    |
| `df.values`        | 获取底层 NumPy 数组   | Pandas → NumPy |
| `df.astype()`      | 转换数据类型          | 转换成模型需要的数据类型   |
