# 处理器寻址（Processor Addressing）详解


# 1. 什么是处理器寻址

处理器寻址（Addressing）是指：

> 处理器通过生成地址信息，定位并访问存储器或外设资源的过程。


处理器执行程序时，需要访问：

- 指令
- 变量
- 堆栈
- 动态内存
- 外设寄存器


这些资源都需要一个唯一的位置标识：

```
地址（Address）
```


例如：

CPU执行：

```c
data = *0x80000000;
```


表示：

```
读取地址0x80000000中的数据
```


处理器并不关心这个地址里面是什么，只负责：

```
产生地址
发送地址
获取数据
```


---

# 2. 为什么处理器需要寻址


计算机中的存储资源很多：

```
              CPU

               |
               |
        ----------------

        |              |

       RAM           外设

        |
        |
       Flash
```


CPU需要一种统一的方法访问这些资源。


因此：

计算机为每个资源分配一个地址。


例如：

```
地址空间

0x00000000
    |
    |
    |  RAM
    |
0x40000000
    |
    |
    |  UART
    |
0x50000000
    |
    |
    |  GPIO
    |
0x80000000
    |
    |
    |  DDR
```


CPU只需要访问地址：

```
0x40000000
```

系统即可知道：

```
访问UART寄存器
```


---

# 3. 处理器寻址基本过程


CPU访问数据：

```
             CPU

              |
              |
          产生地址

              |
              |

          地址总线

              |
              |

       Memory Controller

              |
              |

     ---------------------

     |                   |

    RAM                外设
```


执行过程：

1. CPU执行load/store指令
2. 地址生成单元产生地址
3. 地址发送到总线
4. 总线连接目标设备
5. 数据返回CPU


---

# 4. 地址组成


一个地址通常包含：

```
地址 = 地址编号
```


例如：

32bit地址：

```
0x12345678
```


二进制：

```
00010010 00110100 01010110 01111000
```


每一位参与表示地址。


---

# 5. 地址宽度与寻址范围


处理器拥有地址线：

```
A0
A1
A2
...
An
```


如果：

```
地址线数量 = N
```


那么：

```
最大地址数量：

2^N
```


---

## 5.1 8位地址


地址线：

```
8 bit
```


范围：

```
0 ~ 255
```


数量：

```
256
```


---

## 5.2 32位地址


地址数量：

```
2^32
```


范围：

```
0x00000000

~

0xffffffff
```


空间：

```
4GB
```


---

## 5.3 64位地址


理论：

```
2^64
```


空间：

```
16EB
```


但是实际处理器通常只实现：

```
39bit
48bit
52bit
```


---

# 6. 物理地址空间


物理地址：

Physical Address（PA）


表示：

> CPU最终访问硬件资源的位置。


例如：

```
CPU

 |
 |
物理地址

 |
 |
DDR芯片
```


例如：

```
PA:

0x80000000
```


可能对应：

```
DDR第0个位置
```


---

# 7. 虚拟地址空间


现代处理器通常使用虚拟地址。


程序看到：

```
Virtual Address
(VA)
```


例如：

程序：

```c
int a;

printf("%p",&a);
```


输出：

```
0x7ffff1234000
```


这个地址：

不是实际RAM地址。


它是：

```
虚拟地址
```


---

# 8. MMU地址转换


处理器内部有：

```
MMU
(Memory Management Unit)
```


作用：

```
虚拟地址
      |
      |
     MMU

      |
      |

物理地址
```


例如：

```
程序访问：

VA:
0x400000


MMU转换


PA:
0x80004000
```


最终访问：

```
物理内存
```


---

# 9. 页表（Page Table）


MMU通过页表完成转换。


例如：

虚拟地址：

```
0x400000
```


查找：

```
Page Table


VA              PA

0x400000  ---> 0x800000
0x401000  ---> 0x801000
```


每个映射单位：

```
Page
```


常见：

```
4KB Page
```


---

# 10. ARMv8处理器寻址


ARMv8-A是现代64位处理器架构。


地址类型：

```
VA
 |
 |
MMU
 |
 |
PA
```


ARMv8支持：

```
64bit寄存器
```


但是实际：

```
虚拟地址通常48bit
```


例如：

用户空间：

```
0x0000000000000000

          |

0x00007fffffffffff
```


内核空间：

```
0xffff000000000000

          |

0xffffffffffffffff
```


---

# 11. 指令寻址


处理器不仅访问数据，还需要访问指令。


CPU内部有：

```
PC
Program Counter
```


保存：

```
下一条指令地址
```


例如：

```
PC=0x1000
```


CPU：

```
读取0x1000

执行指令

PC+4
```


ARM：

普通指令：

```
4 Byte
```


所以：

```
PC = PC + 4
```


---

# 12. 数据寻址方式


处理器访问数据时有不同寻址方式。


---

## 12.1 立即寻址


数据直接在指令中。


例如：

```asm
MOV R0,#10
```


表示：

```
R0=10
```


---

## 12.2 寄存器寻址


数据来自寄存器。


例如：

```asm
ADD R0,R1,R2
```


表示：

```
R0=R1+R2
```


---

## 12.3 直接寻址


地址直接给出。


例如：

```
load 0x80000000
```


---

## 12.4 间接寻址


地址存储在寄存器。


例如：

```
R1=0x80000000

load [R1]
```


---

## 12.5 基址+偏移寻址


常用于访问结构体。


例如：

```
address =
base + offset
```


ARM大量使用：

```
LDR R0,[R1,#4]
```


---

# 13. 内存映射IO（MMIO）


现代CPU把外设映射到地址空间。


例如：

```
地址

0x40000000

对应：

UART寄存器
```


代码：

```c
*(volatile uint32_t*)0x40000000
```


实际上：

不是访问RAM。


而是：

访问UART硬件。

# 15. 寻址与总线关系


CPU：

```
产生地址
```


总线：

```
传输地址
```


存储控制器：

```
解析地址
```


例如：

```
CPU

 |
 |
Address Bus

 |
 |
AXI Bus

 |
 |
DDR Controller

 |
 |
Memory
```


注意：

总线负责：

```
传输地址
```


但是：

不负责：

```
地址转换
```

地址转换由：

```
MMU
```


完成。


---

# 16. 寻址与Cache关系


现代CPU：

```
CPU

 |
 |
Cache

 |
 |
Memory
```


CPU访问：

优先：

```
Cache
```


如果Cache没有：

再访问：

```
Memory
```


地址仍然是：

```
虚拟地址
```


Cache内部保存：

```
Tag
Index
Offset
```


用于快速查找。


---

# 17. 多核处理器中的寻址


多核：

```
        CPU0

        CPU1

        CPU2

          |

      Interconnect

          |

        Memory
```


每个CPU都有：

```
自己的Cache
```


访问同一个地址：

```
0x80000000
```


需要：

```
Cache一致性协议
```


例如：

```
MESI
```


保证：

多个CPU看到的数据一致。

---

## 核心概念总结


|概念|作用|
|-|-|
|地址|定位资源的位置|
|地址线|决定寻址范围|
|虚拟地址|程序看到的地址|
|物理地址|硬件真实地址|
|MMU|地址转换|
|页表|保存映射关系|
|Cache|提高访问速度|
|总线|传输地址和数据|
|MMIO|通过地址访问外设|
