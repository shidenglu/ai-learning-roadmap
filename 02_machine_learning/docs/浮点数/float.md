# 浮点数（Floating Point）

## 1. 浮点数是什么

浮点数是一种用于表示实数的计算机数据类型。

由于计算机只能存储有限位的二进制数据，因此无法精确表示所有实数。浮点数通过类似科学计数法的方式，在有限位数内表示较大范围的数值。

十进制科学计数法：

\[
6.5 = 6.5 \times 10^0
\]

二进制浮点表示：

\[
6.5 = 1.101_2 \times 2^2
\]

浮点数的核心思想：

> 使用符号位、指数位和尾数位，将数值表示为二进制科学计数法。

---

## 2. 浮点数的组成

以常见的 IEEE 754 单精度浮点数（FP32）为例：

| 字段 | 位数 | 作用 |
|---|---:|---|
| 符号位 Sign | 1 bit | 表示正数或负数 |
| 指数位 Exponent | 8 bit | 表示数值的指数 |
| 尾数位 Fraction | 23 bit | 表示有效数字部分 |

FP32 总长度：

\[
1 + 8 + 23 = 32\text{ bit}
\]

结构如下：

```text
31          30                 23 22                  0
+------------+------------------+--------------------+
| Sign (1)  | Exponent (8)     | Fraction (23)      |
+------------+------------------+--------------------+
```

### 2.1 符号位

符号位决定数值的正负：

```text
Sign = 0：正数
Sign = 1：负数
```

### 2.2 指数位

指数位用于表示二进制数的指数。

FP32 的指数位为 8 bit，采用偏置表示法（Bias）。

指数偏置：

\[
Bias = 2^{8-1}-1 = 127
\]

实际指数：

\[
e = E - 127
\]

其中：

- `E`：存储的指数值
- `e`：实际指数值

例如：

```text
存储指数 E = 129

实际指数 e = 129 - 127 = 2
```

### 2.3 尾数位

尾数位用于存储有效数字的小数部分。

对于规格化浮点数，二进制有效数字的最高位一定为 `1`，因此该位不需要存储，称为隐藏位（Implicit Leading 1）。

例如：

```text
1.101₂
```

实际存储的尾数部分为：

```text
101
```

隐藏的最高位 `1` 不占用存储空间。

## 3. IEEE 754 FP32 数值表示

对于规格化 FP32 浮点数，其数值计算公式为：

\[
x = (-1)^s \times (1.f)_2 \times 2^{E-127}
\]

其中：

- `s`：符号位
- `f`：尾数位
- `E`：存储的指数值
- `127`：指数偏置

### 3.1 浮点数转换示例

将十进制数 `6.5` 转换为 FP32。

#### 第一步：转换为二进制

整数部分：

```text
6 = 110₂
```

小数部分：

```text
0.5 = 0.1₂
```

因此：

```text
6.5 = 110.1₂
```

#### 第二步：规格化

将二进制数转换为科学计数法：

```text
110.1₂ = 1.101₂ × 2²
```

#### 第三步：计算指数

实际指数：

```text
e = 2
```

存储指数：

```text
E = e + Bias
  = 2 + 127
  = 129
```

129 转换为 8 bit 二进制：

```text
129 = 10000001₂
```

#### 第四步：确定尾数

规格化结果：

```text
1.101₂
```

隐藏最高位 `1`，存储尾数：

```text
10100000000000000000000
```

#### 第五步：组合 32 bit

```text
Sign     = 0
Exponent  = 10000001
Fraction  = 10100000000000000000000
```

最终 FP32：

```text
0 10000001 10100000000000000000000
```

## 4. 浮点数为什么存在精度误差

计算机使用有限位的二进制表示浮点数。

但是，某些十进制小数转换为二进制后会无限循环，无法被有限位数完整存储。

例如：

```text
0.1₁₀ = 0.00011001100110011...₂
```

二进制小数部分会不断重复：

```text
0011 0011 0011 ...
```

FP32 只有 23 bit 尾数位，因此只能保存其中有限位数，剩余部分需要舍入。

所以：

```python
0.1 + 0.2 == 0.3
```

结果可能是：

```text
False
```

实际计算结果可能接近：

```text
0.30000000000000004
```

这并不是计算错误，而是浮点数有限精度表示带来的结果。

### 4.1 浮点数比较

不建议直接使用 `==` 判断两个浮点数是否相等。

可以使用：

```python
import math

a = 0.1 + 0.2
b = 0.3

print(math.isclose(a, b))
```

`math.isclose()` 可以根据允许的误差范围判断两个数是否足够接近。

## 5. 浮点数精度与数值范围

浮点数的两个重要特性：

### 5.1 数值范围

主要由指数位决定。

指数位越多，能够表示的数值范围通常越大。

### 5.2 数值精度

主要由尾数位决定。

尾数位越多，能够表示的有效数字通常越多。

因此：

```text
指数位 → 主要影响数值范围
尾数位 → 主要影响数值精度
```

## 6. 常见浮点数格式

| 类型 | 总位数 | 指数位 | 尾数位 |
|---|---:|---:|---:|
| FP64 | 64 bit | 11 bit | 52 bit |
| FP32 | 32 bit | 8 bit | 23 bit |
| FP16 | 16 bit | 5 bit | 10 bit |
| BF16 | 16 bit | 8 bit | 7 bit |

### 6.1 FP64

双精度浮点数。

特点：

- 数值范围较大
- 精度较高
- 占用 8 字节
- 常用于科学计算和高精度数值处理

### 6.2 FP32

单精度浮点数。

特点：

- 占用 4 字节
- 约有 7 位十进制有效数字
- 数值范围和精度较为均衡
- 常用于普通深度学习模型训练和推理

### 6.3 FP16

半精度浮点数。

特点：

- 占用 2 字节
- 尾数位较少
- 数值范围相对较小
- 最大有限正数为 65504

FP16 可以减少显存占用并提高部分硬件上的计算效率，但较小的数值范围容易产生溢出或下溢。

### 6.4 BF16

Brain Floating Point 16。

特点：

- 占用 2 字节
- 指数位与 FP32 相同，为 8 bit
- 尾数位只有 7 bit
- 数值范围接近 FP32
- 精度低于 FP16 的尾数精度

BF16 具有较大的动态范围，因此在 AI 训练和推理中较为常见。

## 7. 浮点数在 AI 中的应用

深度学习模型中的权重、偏置、激活值通常使用浮点数表示。

例如：

```python
import torch
from torch import nn

model = nn.Linear(2, 1)

x = torch.tensor([[1.0, 2.0]])

y = model(x)

print(y)
```

模型中的计算可以表示为：

\[
z = w_1x_1 + w_2x_2 + b
\]

其中：

- `x`：输入数据
- `w`：模型权重
- `b`：偏置
- `z`：计算结果

训练过程中，模型通过反向传播计算梯度，再由优化器更新权重和偏置。

浮点数用于表示和计算这些参数及中间结果。

### 7.1 为什么 AI 使用低精度浮点数

例如，FP32 每个数占用 4 字节，而 FP16 每个数占用 2 字节。

使用 FP16 或 BF16 可以：

- 减少模型参数的存储空间
- 降低显存或内存占用
- 减少数据传输量
- 提高支持低精度计算的硬件上的运算效率

### 7.2 混合精度

混合精度是指在模型计算过程中使用不同精度的数据类型。

例如：

```text
部分计算使用 FP16 / BF16
部分关键计算使用 FP32
```

这样可以在降低计算成本的同时，尽量保持模型训练的稳定性。

## 8. 浮点数与嵌入式开发

在嵌入式系统中，浮点数和定点数都是常见的数值表示方式。

### 8.1 浮点数

浮点数能够表示较大的数值范围，并且可以处理不同数量级的数值。

适合：

- 数值计算
- 信号处理算法
- AI 模型训练与推理
- 动态范围较大的数据处理

但浮点运算需要相应的硬件或软件支持。

### 8.2 定点数

定点数使用整数表示数值，并通过固定的小数位数解释其实际含义。

例如 Q15 格式：

```text
实际数值 = 存储整数 / 2¹⁵
```

如果存储整数为：

```text
16384
```

则实际数值为：

```text
16384 / 32768 = 0.5
```

定点数的特点：

- 使用整数运算
- 数值格式固定
- 运算效率高
- 需要开发者管理缩放和溢出
- 数值范围与精度由格式设计决定

### 8.3 浮点数与定点数对比

| 特性 | 浮点数 | 定点数 |
|---|---|---|
| 表示方式 | 符号、指数、尾数 | 整数与固定缩放 |
| 数值范围 | 通常较大 | 由位宽和缩放决定 |
| 精度分布 | 随数值大小变化 | 固定小数位精度 |
| 运算成本 | 取决于硬件支持 | 整数运算通常较高效 |
| 使用场景 | AI、科学计算 | DSP、基带、低功耗嵌入式 |

## 9. AI 模型部署中的量化

在嵌入式 AI 部署中，模型通常可以从 FP32 转换为更低精度的数据格式。

例如：

```text
FP32 模型
    ↓
量化（Quantization）
    ↓
INT8 模型
    ↓
嵌入式设备推理
```

INT8 使用 8 bit 整数表示模型参数或激活值。

与 FP32 相比：

- 单个参数占用从 4 字节降低到 1 字节
- 模型存储空间通常可以显著减少
- 整数乘加运算可以利用嵌入式硬件加速
- 需要通过量化缩放参数映射浮点值与整数值

量化可能引入精度损失，因此需要评估量化前后的模型效果。

## 10. Python 查看浮点数二进制表示

可以使用 `struct` 将 Python 浮点数转换为 FP32 位模式。

```python
import struct

value = 6.5

# 将 Python 浮点数转换为 FP32 字节
packed = struct.pack("!f", value)

# 将字节转换为 32 bit 整数
bits = struct.unpack("!I", packed)[0]

# 输出 32 bit 二进制
binary = format(bits, "032b")

print(binary)
```

输出：

```text
01000000110100000000000000000000
```

拆分字段：

```python
sign = binary[0]
exponent = binary[1:9]
fraction = binary[9:]

print("Sign:", sign)
print("Exponent:", exponent)
print("Fraction:", fraction)
```

## 11. PyTorch 中查看数据类型

```python
import torch

x = torch.tensor([1.0, 2.0, 3.0], dtype=torch.float32)

print(x.dtype)
print(x.element_size())
print(x.numel())
print(x.numel() * x.element_size())
```

输出含义：

```text
dtype         → 数据类型
element_size  → 单个元素占用的字节数
numel         → 张量元素总数
```

例如 FP32：

```text
单个元素占用 4 字节
```

如果张量包含 1000 个 FP32 元素：

```text
1000 × 4 = 4000 字节
```

## 12. 总结

浮点数是一种基于二进制科学计数法的数值表示方式。

其核心结构为：

```text
符号位 + 指数位 + 尾数位
```

需要掌握的关键概念：

1. IEEE 754 定义了常见浮点数的表示规则。
2. 指数位主要影响数值范围。
3. 尾数位主要影响数值精度。
4. 浮点数无法精确表示所有实数，因此存在舍入误差。
5. FP32、FP16、BF16 等格式在精度、范围和存储成本上存在差异。
6. AI 训练和推理可以使用低精度浮点数提高计算效率。
7. 嵌入式和基带系统中，定点数常用于高效的数值计算。
8. AI 模型可以通过量化转换为 INT8 等低精度格式，以适应嵌入式部署。

从底层实现角度理解浮点数，有助于进一步学习：

- CPU / DSP 浮点运算
- IEEE 754 硬件实现
- 定点数与 Q 格式
- AI 模型量化
- 嵌入式神经网络推理
