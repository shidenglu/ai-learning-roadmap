# 定点数（Fixed-Point）

## 1. 定点数是什么

定点数（Fixed-Point）是一种计算机数值表示方式。

它通过固定小数点的位置来表示带小数的数值。

与浮点数不同，定点数不使用指数位动态调整小数点的位置，而是通过预先约定的缩放比例，将实际数值转换为整数存储。

例如：

```text
实际数值：12.34

存储整数：1234
缩放比例：100

实际数值 = 1234 / 100 = 12.34
```

计算机实际存储的是整数 `1234`，通过约定的缩放比例解释为 `12.34`。

**核心思想：定点数使用整数存储，通过固定缩放比例表示小数。**

---

## 2. 定点数的基本原理

假设使用一个 8 bit 无符号整数存储数据：

```text
00001000
```

按照普通整数解释：

```text
8
```

如果约定小数部分有 4 bit，则实际表示为：

```text
0000.1000
```

对应实际数值：

```text
0.5
```

因为：

\[
x = \frac{X}{2^n}
\]

其中：

- `X`：存储的整数
- `n`：小数位数
- `x`：实际数值

例如：

\[
x = \frac{8}{2^4}=0.5
\]

因此，同一个二进制数据可以表示不同的实际数值，具体取决于约定的小数位数。

---

## 3. 定点数的数学表示

对于使用 `N` bit 存储、具有 `F` 个小数位的定点数：

\[
x = X \times 2^{-F}
\]

也可以写成：

\[
x = \frac{X}{2^F}
\]

其中：

- `N`：总位宽
- `F`：小数位数
- `X`：存储的整数
- `x`：实际数值

将实际数值转换为定点数：

\[
X = round(x \times 2^F)
\]

这里的 `round` 表示按照指定规则进行舍入。

例如，使用 16 bit 有符号整数，设置 8 个小数位：

\[
x = \frac{X}{2^8}
\]

当实际数值为 `1.5` 时：

\[
X=1.5\times256=384
\]

存储结果：

```text
384 = 00000001 10000000
```

实际解释：

\[
384/256=1.5
\]

## 4. Q 格式（Q Format）

Q 格式是 DSP 和嵌入式开发中常见的定点数表示方法。

通常使用：

```text
Qm.n
```

表示定点数的整数部分和小数部分位数。

其中：

- `m`：整数部分位数
- `n`：小数部分位数

需要注意，不同资料对符号位是否计入 `m` 的定义可能不同，使用时需要确认具体约定。

### 4.1 Q15

Q15 是 DSP 中常见的定点数格式。

通常使用 16 bit 有符号整数表示：

```text
总位宽：16 bit
符号位：1 bit
小数位：15 bit
```

数值转换公式：

\[
x = \frac{X}{2^{15}}
\]

其中：

- `X`：16 bit 有符号整数
- `x`：实际数值

Q15 的数值范围：

\[
-1 \leq x \leq 1-2^{-15}
\]

即：

```text
最小值：-1.0
最大值：0.999969482421875
```

Q15 无法精确表示正数 `1.0`。

### 4.2 Q31

Q31 通常使用 32 bit 有符号整数表示：

```text
总位宽：32 bit
符号位：1 bit
小数位：31 bit
```

数值转换公式：

\[
x = \frac{X}{2^{31}}
\]

数值范围：

\[
-1 \leq x \leq 1-2^{-31}
\]

相比 Q15，Q31 具有更高的数值精度。

### 4.3 Q15 与 Q31 对比

| 格式 | 总位宽 | 小数位 | 数值范围 |
|---|---:|---:|---|
| Q15 | 16 bit | 15 bit | [-1, 1-2⁻¹⁵] |
| Q31 | 32 bit | 31 bit | [-1, 1-2⁻³¹] |

## 5. 定点数的转换

定点数转换分为两个方向：

```text
浮点数 → 定点数
定点数 → 浮点数
```

### 5.1 浮点数转换为定点数

假设将 `0.75` 转换为 Q15。

第一步：确定缩放比例。

\[
Scale=2^{15}=32768
\]

第二步：乘以缩放比例。

\[
X=0.75\times32768=24576
\]

第三步：转换为二进制。

```text
24576 = 01100000 00000000
```

最终：

```text
实际数值：0.75
存储整数：24576
```

### 5.2 定点数转换为浮点数

假设 Q15 存储值为：

```text
X = 16384
```

根据转换公式：

\[
x=\frac{16384}{32768}=0.5
\]

因此，实际数值为：

```text
0.5
```

### 5.3 转换总结

```text
浮点数转定点数：

X = round(x × 2^F)

定点数转浮点数：

x = X / 2^F
```

## 6. 定点数的基本运算

定点数进行运算时，需要特别关注数据的缩放比例。

假设使用 Q15 格式：

```text
a = 0.5
b = 0.25
```

对应存储值：

```text
A = 16384
B = 8192
```

### 6.1 加法

实际计算：

\[
a+b=0.5+0.25=0.75
\]

存储值直接相加：

```text
C = A + B
  = 16384 + 8192
  = 24576
```

结果仍然是 Q15：

\[
24576/32768=0.75
\]

加法要求两个操作数使用相同的缩放比例，或者先进行格式对齐。

### 6.2 减法

实际计算：

\[
a-b=0.5-0.25=0.25
\]

存储值相减：

```text
C = A - B
  = 16384 - 8192
  = 8192
```

结果：

\[
8192/32768=0.25
\]

### 6.3 乘法

实际计算：

\[
a\times b=0.5\times0.25=0.125
\]

存储值相乘：

```text
C = A × B
  = 16384 × 8192
  = 134217728
```

由于两个 Q15 数值相乘：

\[
2^{15}\times2^{15}=2^{30}
\]

因此乘积对应 Q30 格式：

\[
c=\frac{C}{2^{30}}
\]

如果需要转换回 Q15：

```text
Q15_Result = C >> 15
```

计算结果：

```text
134217728 >> 15 = 4096
```

实际数值：

\[
4096/32768=0.125
\]

**注意：定点数乘法会改变小数位数，需要通过移位或缩放调整结果格式。**

### 6.4 除法

假设：

```text
a = 0.5
b = 0.25
```

实际计算：

\[
a/b=2.0
\]

对于两个 Q15 数值：

\[
A = a\times2^{15}
\]

\[
B = b\times2^{15}
\]

为了得到 Q15 格式的结果：

\[
C = \frac{A\times2^{15}}{B}
\]

示例：

```text
A = 16384
B = 8192

C = (16384 × 32768) / 8192
  = 65536
```

这里 `65536` 已经超出 Q15 的最大值，因此结果无法用 Q15 表示。

需要使用更宽的格式，或者调整数值范围和缩放比例。

## 7. 定点数的溢出与精度问题

定点数使用固定的整数位宽存储数据，因此存在数值范围限制。

主要问题：

- 溢出（Overflow）
- 精度损失（Precision Loss）
- 舍入误差（Rounding Error）

### 7.1 溢出

例如 Q15：

```text
最大值 ≈ 0.999969
```

如果执行：

```text
0.8 + 0.5 = 1.3
```

结果超过 Q15 的表示范围。

如果不进行处理，可能出现整数回绕，导致计算结果错误。

### 7.2 回绕（Wrap）

对于 8 bit 无符号整数：

```text
255 + 1 = 0
```

超出最大值后，结果从 0 重新开始。

在有符号整数中，具体行为取决于语言、数据类型和硬件实现；C 语言有符号整数溢出不能简单地假设为回绕。

### 7.3 饱和（Saturation）

饱和运算会将超出范围的结果限制在最大值或最小值。

例如：

```text
Q15 最大值 ≈ 0.999969

0.8 + 0.5 = 1.3

饱和结果 ≈ 0.999969
```

DSP 和数字信号处理中经常使用饱和运算，避免溢出回绕造成严重的信号失真。

### 7.4 舍入与截断

定点数转换时，如果结果无法被当前格式精确表示，就需要进行截断或舍入。

例如：

```text
实际结果：0.123456
目标格式：Q15
```

转换后只能保留有限精度。

- 截断：直接丢弃多余位
- 舍入：根据被舍弃部分调整保留结果

合理的舍入方式有助于减少量化误差。

## 8. 定点数与浮点数的区别

| 对比项 | 定点数 | 浮点数 |
|---|---|---|
| 表示方式 | 整数 + 固定缩放 | 符号 + 指数 + 尾数 |
| 小数点位置 | 固定 | 动态 |
| 数值范围 | 由位宽和缩放决定 | 通常较大 |
| 精度 | 固定分辨率 | 随数值大小变化 |
| 运算 | 整数运算及缩放 | 浮点运算 |
| 溢出处理 | 需要明确管理 | 仍可能发生溢出和下溢 |
| 常见场景 | DSP、基带、低功耗 MCU | AI、科学计算、通用计算 |

### 8.1 定点数的优点

- 可以使用整数运算实现数值计算。
- 在没有硬件浮点单元的处理器上，通常更容易获得高效实现。
- 数据格式和计算行为可以进行精确规划。
- 适合硬件乘加单元和 DSP 运算。

### 8.2 定点数的缺点

- 数值范围受到位宽和缩放比例限制。
- 不同数据格式之间需要进行缩放转换。
- 需要管理溢出、舍入和精度损失。
- 算法设计和调试相对复杂。

## 9. 定点数在 DSP 和基带中的应用

定点数广泛应用于数字信号处理和数字通信系统。

例如，一个典型的 OFDM 基带处理链路：

```text
ADC
 ↓
数字下变频 DDC
 ↓
数字滤波 FIR
 ↓
FFT
 ↓
信道估计 CE
 ↓
信道均衡 EQ
 ↓
解调
```

其中的信号、滤波器系数以及中间计算结果，都可能采用定点格式表示。

### 9.1 FIR 滤波器

FIR 滤波器的计算公式：

\[
y[n]=\sum_{k=0}^{N-1}h[k]x[n-k]
\]

其中：

- `x[n]`：输入信号
- `h[k]`：滤波器系数
- `y[n]`：输出信号

假设输入和滤波器系数都使用 Q15：

```text
输入数据：Q15
滤波器系数：Q15
```

乘法过程：

```text
Q15 × Q15 = Q30
```

累加过程：

```text
多个 Q30 乘积进行累加
```

最终输出：

```text
Q30 累加结果
      ↓
舍入 / 移位
      ↓
Q15 输出
```

### 9.2 为什么需要宽位累加器

FIR 滤波器需要将多个乘积结果累加。

如果每次乘法后立即转换回 Q15，容易造成精度损失。

因此通常采用更宽的累加器，例如：

```text
16 bit 输入
    ↓
16 × 16 bit 乘法
    ↓
32 bit 乘积
    ↓
40 bit 或更宽累加器
    ↓
移位 / 舍入 / 饱和
    ↓
16 bit 输出
```

具体位宽取决于滤波器阶数、输入范围、系数范围和硬件实现。

## 10. C 语言实现 Q15 定点数

下面使用 C 语言模拟 Q15 的基本运算。

```c
#include <stdint.h>
#include <stdio.h>

#define Q15_SCALE 32768

/* 饱和处理 */
static int16_t q15_saturate(int32_t value)
{
    if (value > 32767)
        return 32767;

    if (value < -32768)
        return -32768;

    return (int16_t)value;
}

/* 浮点数转换为 Q15 */
int16_t float_to_q15(float x)
{
    float value = x * Q15_SCALE;

    /* 四舍五入 */
    int32_t result = (int32_t)(value >= 0
                               ? value + 0.5f
                               : value - 0.5f);

    return q15_saturate(result);
}

/* Q15 转换为浮点数 */
float q15_to_float(int16_t x)
{
    return (float)x / Q15_SCALE;
}

/* Q15 加法 */
int16_t q15_add(int16_t a, int16_t b)
{
    int32_t result = (int32_t)a + b;

    return q15_saturate(result);
}

/* Q15 减法 */
int16_t q15_sub(int16_t a, int16_t b)
{
    int32_t result = (int32_t)a - b;

    return q15_saturate(result);
}

/* Q15 乘法 */
int16_t q15_mul(int16_t a, int16_t b)
{
    int32_t result = (int32_t)a * b;

    /* Q30 转换为 Q15 */
    result >>= 15;

    return q15_saturate(result);
}

int main(void)
{
    int16_t a = float_to_q15(0.5f);
    int16_t b = float_to_q15(0.25f);

    int16_t sum = q15_add(a, b);
    int16_t sub = q15_sub(a, b);
    int16_t mul = q15_mul(a, b);

    printf("a = %f\n", q15_to_float(a));
    printf("b = %f\n", q15_to_float(b));

    printf("add = %f\n", q15_to_float(sum));
    printf("sub = %f\n", q15_to_float(sub));
    printf("mul = %f\n", q15_to_float(mul));

    return 0;
}
```

输出：

```text
a = 0.500000
b = 0.250000

add = 0.750000
sub = 0.250000
mul = 0.125000
```

说明：该示例用于演示 Q15 基本原理。实际工程中还需要根据编译器、目标处理器和数据范围处理负数移位、乘法舍入及累加溢出等问题。

## 11. 定点数在 AI 模型量化中的应用

AI 模型通常使用 FP32、FP16、BF16 等浮点数进行训练和推理。

但是在嵌入式设备上，浮点计算可能受到计算资源、内存容量和功耗的限制。

因此，可以使用量化（Quantization）将浮点数转换为整数表示。

例如：

```text
FP32 模型
    ↓
量化
    ↓
INT8 模型
    ↓
嵌入式设备推理
```

### 11.1 INT8 量化

INT8 使用 8 bit 有符号整数表示数据。

常见的量化公式：

\[
q=round\left(\frac{x}{Scale}\right)+ZeroPoint
\]

其中：

- `x`：原始浮点数
- `q`：量化后的整数
- `Scale`：缩放参数
- `ZeroPoint`：零点偏移

反量化公式：

\[
x=(q-ZeroPoint)\times Scale
\]

量化可以减少模型参数和激活值的存储空间，并利用支持整数运算的硬件加速推理。

注意：INT8 量化与 Q15 这类固定小数位的 Q 格式并不完全相同。INT8 量化通常通过 Scale 和 ZeroPoint 描述数值映射，可以采用不同的缩放策略。

## 12. 总结

定点数的核心思想：

**使用整数存储数据，通过固定缩放比例表示实际数值。**

需要掌握的关键知识：

1. 定点数本质上是整数表示。
2. 小数点位置通过缩放比例约定。
3. Q 格式用于描述定点数的整数位和小数位。
4. Q15 和 Q31 是 DSP 中常见的定点格式。
5. 加减法需要对齐缩放比例。
6. 乘法会改变结果的小数位数，需要进行移位和缩放。
7. 定点数需要考虑溢出、饱和、截断和舍入。
8. DSP、FIR、FFT 和基带信号处理中经常使用定点数。
9. AI 模型可以通过 INT8 量化部署到嵌入式设备。
