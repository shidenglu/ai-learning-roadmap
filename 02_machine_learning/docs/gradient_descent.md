# 梯度下降（Gradient Descent）详解


# 1. 什么是梯度下降

梯度下降（Gradient Descent）是一种用于求解最优化问题的算法。

在机器学习和深度学习中，它主要用于：

> 通过不断调整模型参数，使损失函数（Loss Function）达到最小。


模型训练的目标：

$$
\min Loss(W,b)
$$


其中：

| 符号 | 含义 |
|----|----|
| W | 模型权重（Weight） |
| b | 模型偏置（Bias） |
| Loss | 损失函数 |


简单理解：

```
模型预测

↓

计算错误

↓

调整参数

↓

减少错误

↓

得到更好的模型
```


---

# 2. 为什么需要梯度下降


## 2.1 模型训练本质

神经网络通常包含大量参数：

例如：

```
输入层

↓

隐藏层

↓

隐藏层

↓

输出层
```


其中包含：

```
W1

W2

W3

...

b1

b2

b3

...
```


这些参数可能达到：

```
百万级

千万级

甚至十亿级
```


我们无法通过：

```
遍历所有参数组合
```

找到最优答案。


因此需要一种方法：

```
从当前参数开始

不断调整

逐渐接近最优参数
```


这就是：

```
梯度下降
```


---

# 3. 梯度下降的核心思想


梯度下降来源于一个直观思想：

> 如果想找到山谷最低点，就沿着下降最快的方向移动。


类似：

```
              山顶


                *
               / \
              /   \
             /     \
            /       \


                 ↓

              最低点
```


每一步：

```
观察当前位置

↓

寻找下降方向

↓

移动一步

↓

重复执行
```


最终：

```
到达最低点
```


这个最低点对应：

```
Loss最小

模型参数最优
```


---

# 4. 什么是梯度


## 4.1 梯度定义


梯度（Gradient）表示：

> 函数变化最快的方向。


对于损失函数：

$$
Loss(W)
$$


梯度表示：

$$
\frac{\partial Loss}{\partial W}
$$


含义：

```
Loss关于参数W的变化速度
```


---

## 4.2 梯度的方向


梯度方向：

表示：

```
Loss增加最快方向
```


例如：

如果：

$$
\frac{\partial Loss}{\partial W}>0
$$


说明：

```
增加W

Loss会上升
```


因此：

应该：

```
减少W
```


如果：

$$
\frac{\partial Loss}{\partial W}<0
$$


说明：

```
增加W

Loss下降
```


因此：

应该：

```
增加W
```


---

# 5. 梯度下降数学公式


梯度下降核心公式：


$$
W_{new}
=
W_{old}
-
\eta
\frac{\partial Loss}{\partial W}
$$


其中：


| 符号 | 含义 |
|-|-|
| W_old | 当前参数 |
| W_new | 更新后的参数 |
| η | 学习率（Learning Rate） |
| ∂Loss/∂W | 梯度 |


公式含义：


```
新的参数

=

旧参数

-

学习率 × 梯度
```


---

# 6. 为什么要减去梯度


梯度表示：

```
Loss增加最快方向
```


但是我们的目标：

```
Loss最小
```


所以：

需要走相反方向。


因此：

$$
W=W-\eta\nabla Loss
$$


其中：

$$
\nabla Loss
$$

表示梯度。


---

# 7. 学习率（Learning Rate）


学习率：

$$
\eta
$$


表示：

> 每次参数更新的步长。


---

## 7.1 学习率过大


例如：

```
        最低点


          *

       ←     →


参数跳过最低点
```


结果：

```
Loss震荡

无法收敛
```


---

## 7.2 学习率过小


例如：

```
一步

一点

一点

一点
```


结果：

```
训练速度非常慢
```


---

## 7.3 合适学习率


效果：

```
快速下降

稳定收敛
```


---

# 8. 梯度下降训练过程


以线性回归为例：

模型：

$$
y=wx+b
$$


目标：

找到：

```
最佳w

最佳b
```


---

## 第一步：初始化参数


随机初始化：

$$
w=1
$$


$$
b=0
$$


---

## 第二步：前向传播


计算预测值：


$$
\hat y=wx+b
$$


---

## 第三步：计算Loss


例如均方误差：


$$
Loss=
\frac{1}{n}
\sum(y-\hat y)^2
$$


得到：

```
当前预测误差
```


---

## 第四步：反向传播


计算：

$$
\frac{\partial Loss}{\partial w}
$$


$$
\frac{\partial Loss}{\partial b}
$$


得到：

```
参数调整方向
```


---

## 第五步：更新参数


更新：

$$
w=w-\eta
\frac{\partial Loss}{\partial w}
$$


$$
b=b-\eta
\frac{\partial Loss}{\partial b}
$$


---

## 第六步：重复


不断循环：

```
预测

↓

计算Loss

↓

计算梯度

↓

更新参数

↓

Loss下降
```


直到：

```
模型收敛
```


---

# 9. 一个简单数学例子


假设：

$$
Loss=W^2
$$


求梯度：

$$
\frac{dLoss}{dW}=2W
$$


初始化：

```
W=5
```


学习率：

```
η=0.1
```


---

第一次更新：


梯度：

$$
2\times5=10
$$


更新：

$$
W=5-0.1\times10
$$


得到：

```
W=4
```


---

第二次：


梯度：

$$
2\times4=8
$$


更新：

$$
W=4-0.1\times8
$$


得到：

```
W=3.2
```


继续：


```
5

↓

4

↓

3.2

↓

...

↓

0
```


最终：

```
Loss达到最小
```

# 10. 三种梯度下降方式


## 10.1 批量梯度下降（Batch Gradient Descent）


定义：

每次使用：

```
全部训练数据
```

计算梯度。


例如：

数据：

```
10000个样本
```


一次计算：

```
10000个样本
```


优点：

```
梯度稳定
```


缺点：

```
计算量大
```


---

## 10.2 随机梯度下降（SGD）


定义：

每次：

```
随机选择一个样本
```


更新参数。


优点：

```
速度快
```


缺点：

```
波动较大
```


---

## 10.3 小批量梯度下降（Mini-Batch）


深度学习最常用。


例如：

训练数据：

```
60000张图片
```


设置：

```
batch_size=256
```


每次：

```
取256个样本

计算梯度

更新参数
```


优点：

结合：

```
Batch稳定性

+

SGD速度
```


---

# 11. 三种梯度下降比较


| 方法 | 使用数据 | 优点 | 缺点 |
|-|-|-|-|
| Batch GD | 全部数据 | 稳定 | 慢 |
| SGD | 一个样本 | 快 | 波动大 |
| Mini-Batch | 一批数据 | 综合效果最好 | 需要调整batch大小 |

# 13. 梯度消失问题


深层网络：

```
输入

↓

Layer1

↓

Layer2

↓

Layer3

↓

...

↓

输出
```


反向传播时：

梯度不断相乘。


如果：

```
梯度 < 1
```


会导致：

```
越来越小
```


最终：

```
参数无法更新
```


称为：

```
梯度消失
```


解决方法：

- 使用ReLU激活函数
- 使用Batch Normalization
- 使用残差网络ResNet
- 合理初始化参数


---

# 14. 梯度爆炸问题


如果梯度过大：

```
参数更新幅度巨大
```


导致：

```
Loss震荡

模型无法收敛
```


解决方法：

- 降低学习率
- 梯度裁剪
- BatchNorm
- 合理初始化

# 18. 总结


梯度下降的本质：

```
通过计算损失函数关于参数的梯度

不断调整参数

使Loss越来越小
```


核心公式：

$$
W_{new}
=
W_{old}
-
\eta
\frac{\partial Loss}{\partial W}
$$


牢记：

```
损失函数

告诉模型错在哪里


梯度

告诉模型往哪里改


学习率

告诉模型改多少


梯度下降

负责完成参数更新
```


梯度下降是现代机器学习和深度学习模型训练的核心优化算法。
