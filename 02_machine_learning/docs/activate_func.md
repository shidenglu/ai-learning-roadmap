# 激活函数（Activation Function）详解

## 1. 什么是激活函数

激活函数（Activation Function）是神经网络中的一个重要组成部分，用于：

> 给神经网络引入非线性能力，使模型能够学习复杂的数据规律。

神经网络中的每个神经元首先进行线性计算：

$$
z=Wx+b
$$

然后经过激活函数：

$$
a=f(z)
$$

其中：

| 符号 | 含义 |
|----|----|
| x | 输入数据 |
| W | 权重参数 |
| b | 偏置参数 |
| z | 线性计算结果 |
| f() | 激活函数 |
| a | 神经元输出 |

完整过程：

```
输入 x
  |
  ↓
线性计算

z = Wx+b

  |
  ↓
激活函数

a=f(z)

  |
  ↓
输出
```

---

# 2. 为什么需要激活函数

## 2.1 没有激活函数的问题

假设一个神经网络：

```
输入层

 ↓

Linear层

 ↓

Linear层

 ↓

输出
```

第一层：

$$
y=W_1x+b_1
$$


第二层：

$$
z=W_2y+b_2
$$


代入：

$$
z=W_2(W_1x+b_1)+b_2
$$


展开：

$$
z=W_2W_1x+W_2b_1+b_2
$$


可以发现：

最终仍然可以表示为：

$$
z=Wx+b
$$


也就是说：

```
多个线性层

等价于

一个线性层
```

因此：

> 如果没有激活函数，无论网络有多少层，本质上仍然只能学习线性关系。

---

# 3. 加入激活函数后的网络

加入激活函数：

$$
a=f(Wx+b)
$$


网络结构：

```
输入

 ↓

Linear

 ↓

Activation

 ↓

Linear

 ↓

Activation

 ↓

输出
```

此时网络具有：

```
非线性表达能力
```

可以学习：

- 图片特征
- 语音特征
- 文本语义
- 复杂函数关系

---

# 4. 激活函数的作用

## 4.1 引入非线性

现实世界的数据通常不是简单线性关系。

例如：

图像识别：

```
像素

 ↓

边缘

 ↓

纹理

 ↓

物体
```

这些特征需要多层非线性变换才能学习。

---

## 4.2 控制输出范围

例如 Sigmoid：

输出：

$$
0 \sim 1
$$

可以表示概率：

```
猫:

0.95


狗:

0.05
```

---

## 4.3 改善梯度传播

训练神经网络需要：

```
前向传播

↓

计算Loss

↓

反向传播

↓

更新参数
```

激活函数会影响：

- 梯度大小
- 收敛速度
- 模型性能

# 6. Sigmoid 激活函数

## 6.1 数学公式

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$


输出范围：

$$
0 < \sigma(x)<1
$$


---

## 6.2 特点

输入：

```
-∞ -------- 0 -------- +∞
```

输出：

```
0 ---------0.5---------1
```

---

## 6.3 优点

### 输出概率

例如：

二分类：

```
猫:

0.9

狗:

0.1
```

---

## 6.4 缺点

### 梯度消失

Sigmoid导数：

$$
\sigma'(x)=\sigma(x)(1-\sigma(x))
$$


最大值：

$$
0.25
$$


当：

```
x很大

或者

x很小时
```

梯度接近：

```
0
```

导致：

```
网络学习速度变慢
```

---

## 6.5 应用

现在主要用于：

```
二分类模型输出层
```

PyTorch：

```python
nn.Sigmoid()
```

---

# 7. Tanh 激活函数


## 7.1 数学公式


$$
tanh(x)=
\frac{e^x-e^{-x}}
{e^x+e^{-x}}
$$


输出范围：

$$
-1 \sim 1
$$


---

## 7.2 优点

相比 Sigmoid：

```
输出中心为0
```

有利于优化。

---

## 7.3 缺点

仍然存在：

```
梯度消失问题
```

---

## 7.4 应用

早期：

```
RNN循环神经网络
```

---

# 8. ReLU 激活函数

ReLU：

Rectified Linear Unit

目前深度学习中最常用激活函数。

---

## 8.1 数学公式


$$
ReLU(x)=max(0,x)
$$


含义：

```
如果 x > 0

输出 x


如果 x <= 0

输出 0
```

---

## 8.2 示例


输入：

```
[-3,-1,0,2,5]
```


输出：

```
[0,0,0,2,5]
```

---

## 8.3 优点

### 1. 计算简单

只需要：

```
判断正负
```

计算速度快。


---

### 2. 缓解梯度消失

正数区域：

$$
ReLU'(x)=1
$$


梯度可以直接传播。


---

### 3. 稀疏激活

例如：

输入：

```
[-5,-2,3,6]
```

输出：

```
[0,0,3,6]
```

部分神经元关闭：

```
网络更加稀疏
```

---

## 8.4 缺点

### Dead ReLU问题

如果：

```
神经元输出长期小于0
```

那么：

```
输出 = 0

梯度 = 0
```

导致：

```
神经元死亡
```

---

## 8.5 PyTorch

```python
nn.ReLU()
```

---

# 9. Leaky ReLU

Leaky ReLU 是 ReLU 的改进版本。

---

## 9.1 公式


$$
f(x)=
\begin{cases}
x,&x>0\\
\alpha x,&x\le0
\end{cases}
$$


其中：

$$
\alpha=0.01
$$


---

## 9.2 解决的问题

ReLU：

```
负数区域:

梯度=0
```


Leaky ReLU：

```
负数区域:

保留小梯度
```

避免神经元死亡。

---

## 9.3 PyTorch

```python
nn.LeakyReLU()
```

# 10. GELU 激活函数


GELU：

Gaussian Error Linear Unit


公式：

$$
GELU(x)=x\Phi(x)
$$


特点：

```
比ReLU更加平滑
```

---

## 应用

```
Transformer

GPT
```

大量使用 GELU。

---

PyTorch：

```python

```

# 11. Softmax 激活函数

Softmax主要用于：

```
多分类问题输出层
```

---

## 11.1 数学公式


$$
Softmax(x_i)
=
\frac{e^{x_i}}
{\sum_j e^{x_j}}
$$


---

## 11.2 作用

将网络输出：

```
任意数值
```

转换为：

```
概率分布
```

例如：

模型输出：

```
[2.0,1.0,0.5]
```

Softmax：

```
[0.63,0.23,0.14]
```

表示：

```
63%概率属于第一类
23%概率属于第二类
14%概率属于第三类
```

---

# 12. 激活函数比较

| 激活函数 | 输出范围 | 优点 | 缺点 | 常用位置 |
|-|-|-|-|-|
| Sigmoid | 0~1 | 输出概率 | 梯度消失 | 二分类输出 |
| Tanh | -1~1 | 零中心 | 梯度消失 | RNN |
| ReLU | 0~∞ | 快速、简单 | Dead ReLU | CNN/MLP |
| Leaky ReLU | -∞~∞ | 减少死亡问题 | 参数需要设置 | CNN |
| GELU | -∞~∞ | 平滑 | 计算复杂 | Transformer |
| Softmax | 0~1 | 输出概率 | 只能输出层使用 | 多分类 |

# 16. 总结

激活函数的核心作用：

```
给神经网络增加非线性能力
```

没有激活函数：

```
深层网络

≈

单层线性模型
```

常见选择：

```
隐藏层:

ReLU


Transformer:

GELU


二分类输出:

Sigmoid

Softmax
```

```
线性层负责计算

激活函数负责增加非线性

损失函数负责评价错误

优化器负责调整参数
```

激活函数是深度神经网络能够学习复杂规律的关键组成部分。
