# 损失函数（Loss Function）全面详解

## 1. 什么是损失函数

损失函数（Loss Function）是机器学习和深度学习中用于衡量：

> 模型预测结果与真实结果之间差距大小的函数。

简单来说：

```text
预测得越准
    ↓
Loss 越小

预测得越差
    ↓
Loss 越大
```

损失函数相当于模型训练过程中的“评分老师”。

---

## 2. 为什么需要损失函数

假设我们要训练一个房价预测模型：

| 房屋面积(m²) | 真实房价(万元) |
|------------|-------------|
| 80 | 100 |
| 100 | 120 |
| 120 | 150 |

模型预测：

| 房屋面积(m²) | 真实值 | 预测值 |
|------------|--------|--------|
| 80 | 100 | 95 |
| 100 | 120 | 125 |
| 120 | 150 | 160 |

模型如何知道：

```text
95 好不好？

125 准不准？

160 偏差大不大？
```

必须有一个评价标准。

这个评价标准就是：

```text
损失函数（Loss Function）
```

---

# 3. 损失函数的作用

损失函数负责：

```text
比较
真实值 y

和

预测值 ŷ
```

然后计算：

```text
误差有多大
```

数学表示：

```math
Loss = f(y,\hat y)
```

其中：

```text
y      真实值

ŷ      预测值
```

---

# 4. 损失函数在训练中的位置

深度学习训练流程：

```text
输入数据
    ↓
前向传播
    ↓
得到预测值
    ↓
计算损失
    ↓
反向传播
    ↓
计算梯度
    ↓
优化器更新参数
    ↓
继续训练
```

可以看到：

```text
Loss
```

连接着：

```text
前向传播

和

反向传播
```

是整个训练过程的核心。

---

# 5. 损失函数的本质

训练模型实际上是在做：

```text
不断修改参数

让Loss越来越小
```

例如：

真实值：

```text
100
```

预测值：

```text
80
```

损失：

```text
20
```

经过训练：

```text
90
```

损失：

```text
10
```

继续训练：

```text
98
```

损失：

```text

```

最终：

```text
100
```

损失：

```text
训练模型

```

# 7. MSE（均方误差）

## 定义

MSE（Mean Squared Error）：

```math
MSE=
\frac{1}{n}
\sum_{i=1}^{n}
(y_i-\hat y_i)^2
```

---

## 计算示例

真实值：

```text
100
120
150
```

预测值：

```text
95
125
160
```

误差：

```text
-5
5
10
```

平方：

```text
25
25
100
```

平均：

```text
(25+25+100)/3

= 50
```

因此：

```text
MSE = 50
```

---

## 为什么要平方

如果直接求和：

```text
-5 + 5 = 0
```

误差会相互抵消。

平方后：

```text
25 + 25 = 50
```

不会抵消。

同时：

```text
大误差受到更大的惩罚
```

例如：

| 误差 | 平方后 |
|--------|--------|
| 1 | 1 |
| 2 | 4 |
| 5 | 25 |
| 10 | 100 |

---

## PyTorch实现

```python
loss_fn = nn.MSELoss()
```

# 8. MAE（平均绝对误差）

## 定义

```math
MAE=
\frac1n
\sum |y_i-\hat y_i|
```

---

## 示例

```text
|100-95| = 5

|120-125| = 5

|150-160| = 10
```

平均：

```text
(5+5+10)/3

= 6.67
```

---

## 特点

优点：

```text
对异常值不敏感
```

例如：

```text
真实值 = 100

预测值 = 1000
```

MSE：

```text
810000
```

MAE：

```text
900
```

MAE更加稳定。

# 10. 交叉熵损失（Cross Entropy）

深度学习中最常用的分类损失函数。

---

## 二分类交叉熵

公式：

```math
Loss=
-(y\log(\hat y)
+
(1-y)\log(1-\hat y))
```

---

### 情况1

真实：

```text
y = 1
```

预测：

```text
ŷ = 0.99
```

说明：

```text
99%概率是正确类别
```

Loss：

```text
接近0
```

---

### 情况2

真实：

```text
y = 1
```

预测：

```text
ŷ = 0.01
```

说明：

```text
只有1%概率预测正确
```

Loss：

```text
非常大
```

---

### 交叉熵特点

```text
预测正确
    ↓
Loss 很小

预测错误
    ↓
Loss 很大
```

非常符合训练需求。

---

# 12. 损失函数与梯度下降

训练目标：

```math
\min Loss(W,b)
```

即：

```text
寻找最优参数

使Loss最小
```

---

梯度下降更新公式：

```math
W =
W -
lr
\frac{\partial Loss}{\partial W}
```

```math
b =
b -
lr
\frac{\partial Loss}{\partial b}
```

其中：

```text
lr
```

表示：

```text
学习率（Learning Rate）
```

---

# 16. 常见面试题

## 为什么分类任务不用MSE？

因为：

```text
MSE梯度容易变小

训练速度慢
```

交叉熵：

```text
梯度更合理

收敛更快
```

因此：

```text
分类问题
→ CrossEntropyLoss

回归问题
→ MSELoss
```

---

## Loss越小越好吗？

通常是：

```text
Loss越小

训练效果越好
```

但如果：

```text
训练Loss很小

测试Loss很大
```

则说明：

```text
发生了过拟合
```
